# Odin Recipes

Projet de recettes créé dans le cadre du cours Odin Project.  
Ce site présente une collection de recettes faciles, rapides et savoureuses à réaliser à la maison.

## Description

Odin Recipes est une petite application web statique dédiée aux recettes de cuisine.  
L’objectif est de proposer un catalogue visuel de plats variés pour aider les utilisateurs à trouver des idées de repas, surtout pour les personnes qui souhaitent cuisiner simplement et avec plaisir.

## Objectifs du projet

- Présenter une sélection de recettes modernes et attractives
- Donner un design simple, propre et agréable visuellement
- Créer une interface facile à utiliser sur ordinateur et mobile
- Ajouter plusieurs recettes pour couvrir différents types de repas
- Développer un projet HTML/CSS de base en respectant les principes du Odin Project

## Fonctionnalités

- Page d’accueil élégante avec une grille de recettes
- Carte visuelle pour chaque recette
- Mise en page moderne et responsive
- Navigation simple entre les différentes recettes
- Nombre de recettes supérieur à 20
- Présentation claire et professionnelle du projet
